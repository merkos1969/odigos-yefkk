# Υπολογιστής Μίδας ΥΕΦΚΚ — V5.36 (εικονίδια στη ρίζα)

## Περιεχόμενα
- `index.html`: εφαρμογή.
- `manifest.json`: ρυθμίσεις εγκατάστασης PWA.
- `sw.js`: βασική προσωρινή αποθήκευση για χρήση εκτός σύνδεσης.
- `icon-180.png`, `icon-192.png`, `icon-512.png`: εικονίδια στο κεντρικό επίπεδο του repository (χωρίς φάκελο `icons`).

## Εγκατάσταση
Ανέβασε όλα τα παραπάνω αρχεία στο ίδιο επίπεδο (root) του GitHub repository. Οι διαδρομές στο HTML, στο manifest και στο service worker έχουν ήδη προσαρμοστεί ώστε να δείχνουν απευθείας στα αρχεία εικονιδίων.

Η εγκατάσταση PWA απαιτεί φιλοξενία μέσω HTTPS.
- Android / Chrome: Μενού ⋮ → Εγκατάσταση εφαρμογής ή το κουμπί εγκατάστασης της σελίδας.
- iPhone / Safari: Κοινή χρήση → Προσθήκη στην οθόνη Αφετηρίας.
