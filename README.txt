# Υπολογιστής Μίδας ΥΕΦΚΚ — V5.36

## Περιεχόμενα
- `index.html`: εφαρμογή V5.35 με ενημερωμένα στοιχεία εγκατάστασης V5.36.
- `manifest.json`: όνομα, εμφάνιση και εικονίδια PWA.
- `sw.js`: βασική προσωρινή αποθήκευση για χρήση εκτός σύνδεσης.
- `icons/`: εικονίδια 180, 192 και 512 px.

## Εγκατάσταση
Η εγκατάσταση PWA απαιτεί να φιλοξενείται ο φάκελος σε HTTPS.
- Android / Chrome: Μενού ⋮ → Εγκατάσταση εφαρμογής ή το κουμπί εγκατάστασης της σελίδας.
- iPhone / Safari: Κοινή χρήση → Προσθήκη στην οθόνη Αφετηρίας.

Το άνοιγμα από απλή τοπική διεύθυνση HTTP (π.χ. τοπικό IP) δεν ενεργοποιεί εγκατάσταση PWA σε κινητό.
