# ΕΞΩΤΕΡΙΚΗ ΦΡΟΥΡΗΣΗ — Υπηρεσιακός Οδηγός ΥΕΦΚΚ

V4.34 — πλήρες πακέτο για GitHub Pages / PWA.

## Περιεχόμενα
- `index.html` — εφαρμογή
- `manifest.json` — PWA εγκατάσταση
- `sw.js` — service worker / offline cache
- `icons/icon-192.png` — εικονίδιο PWA
- `icons/icon-512.png` — εικονίδιο PWA

## GitHub Pages
Ανέβασε όλα τα παραπάνω αρχεία διατηρώντας τον φάκελο `icons/` και ενεργοποίησε GitHub Pages από το branch/folder που περιέχει το `index.html`.

Η εγκατάσταση ως εφαρμογή απαιτεί HTTPS (όπως το GitHub Pages).
